## Opnametips

* Zet de bestellijst-onderdelen en leveranciers uit de README klaar vóór de
  opname (de module levert ze niet mee). Importeren kan via
  **Projectopvolging → Bestellijst importeren**.
* Een lijn die te laat is krijgt het label "Te laat"; toon dat met een
  verwachte leverdatum in het verleden.

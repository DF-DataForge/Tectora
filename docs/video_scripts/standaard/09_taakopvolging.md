## Opnametips

* De module levert geen fases of sjablonen mee: zet de demofases en
  -sjablonen uit de README klaar vóór de opname.
* Voor een bestaand project zonder taken verschijnt de knop
  **Taakopvolging starten**.
* Bestaande projecten behouden hun taken als u de sjablonen later wijzigt.
